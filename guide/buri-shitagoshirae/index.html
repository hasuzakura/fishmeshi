ブリ・ハマチの下処理｜大型魚のさばき方と部位の分け方

2026-08-01｜藤原

ブリやハマチが釣れると嬉しいが、家に帰ってから途方に暮れることがある。60cmを超える魚は、まな板からはみ出し、包丁が骨に負ける。大型魚の下処理は技術というより準備の問題で、道具と場所が揃えばあとは小型魚と同じ手順の繰り返しになる。

先に道具と場所を用意する

包丁が小さいと、背骨に当たったところで進まなくなる。まな板が小さいと、魚が滑って危ない。

  • 出刃包丁：刃渡り165〜180mmは欲しい。三徳包丁では骨に負ける
  • まな板：魚が収まるサイズ。無ければシンクに板を渡す、段ボールにラップを巻いて代用するなど
  • キッチンペーパー：大量に使う。血と水気を拭き続けることになる
  • ゴミ袋：アラと内臓の量が多い。先に用意しておく

作業を始める前に流し台を空にしておくと、途中で手が止まらない。大型魚は工程が長いので、段取りが仕上がりに効いてくる。

釣り場でやること

青物は暴れる時間が長いほど身に熱と乳酸がこもり、身が焼けて味が落ちる。釣れたらすぐ処理する。

  1. エラの付け根と尾の付け根に刃を入れ、海水を張ったバケツで血を抜く。
  2. 血が抜けたら、大型クーラーの潮氷に入れる。魚が入りきらない場合は、袋に入れて氷を当てる。
  3. クーラーは日陰に置き、開け閉めを減らす。

ブリは体温が上がりやすく、締めずに置くと身が白く濁る「身焼け」を起こす。こうなると刺身には向かなくなる。

潮氷の作り方は釣った魚の持ち帰り方にまとめてある。

手順1：ウロコを取る

ブリのウロコは細かく、皮に張り付いている。タイのように飛び散らないので作業自体は楽だ。

ウロコ取りか包丁の背で、尾から頭へ向かって落とす。ぬめりが強いので、先に塩をふって水で流すと作業しやすい。

皮を引いて刺身にするなら、ウロコ取りは軽くて構わない。皮ごと焼くなら丁寧に落とす。

手順2：頭とカマを落とす

大型魚は最初に大きく分解してしまうと、その後の取り回しが一気に楽になる。

  1. 胸びれと腹びれを頭側に含めるように、斜めに包丁を入れる。
  2. 裏返して同じ角度で入れ、背骨まで達したら包丁の刃元で押し切る。
  3. 落とした頭を縦に割り、カマ（胸びれの付け根の身）を切り分ける。

カマは焼くと脂が乗っていて美味しい部位で、捨てるのはもったいない。頭を落とすときにカマを頭側に付けておくと、あとで分けやすい。

背骨が硬くて切れないときは、無理をせず包丁を抜き、少し位置をずらして入れ直す。刃をこじると欠ける。

手順3：内臓を出す

  1. 腹を肛門から頭側へ切り開く。
  2. 内臓を取り出す。量が多いので、先にゴミ袋を口を開けて置いておく。
  3. 背骨に沿った血合いを掻き出す。ブリの血合いは厚く、色も濃い。
  4. 腹の中を流水で洗い、水気を拭く。

内臓を洗った水が身にかかり続けないよう気をつける。大型魚は作業時間が長いので、身が水を吸いやすい。

手順4：三枚におろす

小型魚のように一気に切ろうとしないのがコツになる。背側と腹側から別々に切り進める。

  1. 背を手前にして置き、背びれの上に沿って浅く切り込む。
  2. 同じ線を3〜4回なぞり、背骨に達するまで深くする。
  3. 魚を回して腹側を手前にし、腹びれの下から同じように切り進める。
  4. 背骨の上に包丁を寝かせて差し入れ、尾に向かって滑らせて片身を外す。
  5. 裏返して同じ手順で二枚目を取る。

包丁を長く使い、引きながら切る。押して切ろうとすると身が潰れる。

おろした身は、背身と腹身に分けてから腹骨を削ぐ。大きい魚は柵取りまで済ませてしまうと、保存も調理も扱いやすくなる。

部位を使い分ける

  • 背身：脂が控えめで身が締まっている。刺身、しゃぶしゃぶ向き
  • 腹身（ハラス）：脂が多い。塩焼き、照り焼き向き
  • カマ：焼き物の定番。塩をふって焼くだけでいい
  • アラ（中骨・頭）：アラ汁、ブリ大根
  • 血合い：加熱して食べる。生姜と一緒に煮ると臭みが出ない

同じ魚でも部位で脂の量がまったく違うので、全部を同じ料理に使うのはもったいない。刺身と焼き物と汁物に分けると、一匹で三日分の献立になる。

ブリのレシピはブリのページ、ハマチはハマチのページにまとめてある。

ブリ糸状虫を知っておく

ブリをおろすと、血合いのあたりに赤い糸のようなものが入っていることがある。長さは数cmから数十cmになる。

これはブリ糸状虫で、ブリ類に寄生する線虫だ。名前も見た目も不安になるが、人には寄生せず、食べても害はないとされている。加熱や冷凍で処理する必要もない。

ただし見た目が良くないので、見つけたら箸やピンセットで引き出して取り除く。身の色に紛れているので、血合い付近を明るい場所で確認するとよい。

ブリ糸状虫とは別に、ブリにもアニサキスは寄生する。こちらは人に症状を起こす。生食する場合は内臓を早く抜き、身を目視で確認する。

アニサキスの見分け方と対処はサバの下処理とアニサキス対策にまとめてある。白く不透明で渦を巻いているのがアニサキス、赤くて細長いのがブリ糸状虫、と覚えておくと現場で迷わない。

寝かせて食べる

ブリのような大型の青物は、釣った当日より1〜2日置いたほうが旨味が出る。死後硬直が解けて、旨味成分が増えるためだ。

  1. 柵に取り、水気をよく拭く。
  2. キッチンペーパーで包み、その上からラップで包む。
  3. 冷蔵庫のチルド室に入れる。
  4. 1日ごとにペーパーを取り替える。

ペーパーを替えるのは、出てきた水分（ドリップ）を身に戻さないためだ。これを怠ると生臭くなる。

寝かせるのは、血抜きと冷却がきちんとできている魚に限る。処理が甘い魚を置くと、熟成ではなく単に傷む。

当日は歯ごたえ、翌日は旨味。同じ魚で味が変わるのを確かめられるのは、釣った人の特権といっていい。

保存

  • 冷蔵：柵のまま2〜3日（血抜きが済んでいる場合）
  • 冷凍：1回分ずつ柵で包んで2〜3週間。脂が多いぶん白身より短い
  • アラ：早めに使う。冷凍するなら霜降りしてから

一匹が大きいので、最初にどこまで食べてどこから冷凍するかを決めてから作業すると無駄がない。詳しくは釣った魚の冷凍と保存を参照してほしい。
